# 02 — Diagnóstico Visual

> Análisis del estado visual actual de la marca y lineamientos para el refactor.

## Elementos recurrentes de identidad

La identidad gira alrededor de: **diente, tecnología y gestión digital**. El ícono combina un diente con circuitos y una nube — comunica sector dental con enfoque tecnológico.

Recursos visuales recurrentes: degradados azules, fondos limpios, esquinas redondeadas, sombras suaves, composición centrada.

## Uso del logo

- Funciona mejor como **símbolo compacto** (formato app/plataforma).
- Centrado arriba, pequeño, con aire alrededor → orden, profesionalismo, confianza.
- En redes: sello discreto, no gigante. Debe verse sin competir con el mensaje.

## Paleta de colores

| Color | Rol |
|-------|-----|
| Azul profundo | Confianza, tecnología, seguridad |
| Celeste | Innovación, frescura, digitalización |
| Blanco | Limpieza, orden, profesionalismo |
| Gris azulado | Textos secundarios, equilibrio visual |

## Imágenes recomendadas

**Usar:**
- Mockups de plataforma
- Capturas estilizadas de interfaz
- Técnicos dentales en contextos limpios y profesionales
- Laboratorios ordenados, modernos, bien iluminados
- Íconos lineales: procesos, comunicación, órdenes, productividad, capacitación

**Evitar:**
- Imágenes clínicas o primerísimos planos de bocas/dientes
- Cualquier cosa que baje la percepción tecnológica y profesional

## Jerarquía de texto (patrón a mantener)

1. Logo pequeño arriba
2. Título fuerte principal
3. Subtítulo explicativo breve
4. Campos o bloques de acción
5. Botón principal con degradado

Para todo el sitio: **mensaje principal grande, explicación breve, CTA claro**.

## Percepción de marca

- Tecnológica
- Profesional
- Confiable
- Moderna
- No demasiado juvenil
- No excesivamente corporativa
- Premium accesible

Tono ideal: *"Entiendo tu trabajo como técnico dental y te ayudo a organizarlo mejor."*

## Mantener en el refactor

- Paleta azul / celeste / blanco
- Estética tecnológica
- Composición limpia
- Degradados controlados
- Bordes redondeados
- Sombras suaves
- Íconos lineales
- Mensajes breves
- Enfoque en gestión, productividad y profesionalización

## Evitar en el refactor

- Diseños cargados
- Mezclar muchas tipografías
- Imágenes dentales invasivas
- Fotos clínicas frías o poco aspiracionales
- Saturar con el logo
- Lenguaje demasiado técnico
- Venta agresiva en cada sección
- Prometer resultados imposibles

## Oportunidades de mejora (sin perder identidad)

- Plantilla base para secciones educativas
- Plantilla para promoción de lanzamiento
- Línea de carruseles con portada fuerte
- Mockups de plataforma para explicar funcionalidades
- Íconos consistentes para: órdenes, dentistas, comunicación, entregas, capacitación, productividad
- Frases cortas con alto contraste (legibles en móvil)
